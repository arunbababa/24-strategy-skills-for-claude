## 黙って修正していない原文の疑問点

- `decision-memo` の例は、設備投資120万ドル・年間節約40万ドル・回収14か月を同時に挙げる。この情報だけでは単純回収は36か月となり、14か月の裏付けが不足する。翻訳では全数値を原文どおり残した。
- `negotiation-prep` の手順3は留保価格を「それを下回ったら撤退すべき数字」と説明する。売り手の最低受取額には合うが、買い手の最大支払額では撤退する向きが逆になる。原文の表現を保ち、一般論として一律に扱わないようここに注記する。相手の留保価格が推定である点も本文どおり保持した。
- `narrative-builder` の例は40枚の資料から、1枚の主張と3枚の論拠へ再構成し「残り30枚」を付録にすると述べる。枚数の内訳は合計しないが、翻訳で補間しなかった。
- 原文 README は `assets/overview.png` を参照するが、対象 commit の追跡ファイルにその画像が存在しない。日本語版では元の参照を HTML コメントに保存し、表示できない理由を本文へ明記した。
- `CONTRIBUTING.md` は README 上部の「バッジの件数」を更新するよう述べるが、この原文 README に件数バッジは見当たらない。手順を削らず訳した。
