# ユニットエコノミクスの健全性確認

> [英語原文](../../../skills/unit-economics-health-check/SKILL.md)

> **description 日本語訳:** 顧客の存続期間を通じて解約率が現実的に低下するモデルを持つ付属ツールで、LTV:CAC 比率と CAC 回収期間を求める。解約が初期に集中する場合（ほぼ常にそうなる）、LTV を過大評価する「ARPU ÷ 一定解約率」の単純式を避ける。成長投資の健全性、顧客獲得予算の増額、取締役会・投資家向けの LTV:CAC が必要なとき、永久に同じ解約率を仮定した計算があるときに使う。

## 使用する場面
成長・マーケティングの予算判断が、顧客獲得によって売上だけでなく実際に価値が生まれるかに依存する場合に使う。獲得費の増額前、LTV:CAC が必要な取締役会・投資家との話し合いの前、実際の解約率が時間とともに一定か確認せず「平均売上 ÷ 解約率」の短縮式を使っているときに使う。

## 実行すること
一定の解約率ではなく、実際または推定した解約曲線で、月ごとの顧客生涯価値をモデル化する。将来の限界利益を現在価値へ割り引き、付属ツールで LTV:CAC と CAC 回収期間を計算する。新規顧客は通常、長期顧客より早く解約するのに、成熟コホートの低く安定した率を初月から適用するという、最も一般的な過大評価を捉える。

## 方法
1. **CAC を集める。** 広告費だけでなく営業・マーケティング費を含む、顧客獲得1件当たりの総費用を使う。営業チームやコンテンツ制作の費用を除くと CAC が過小となり、比率を押し上げる。
2. **顧客当たり月間売上と粗利益率を集める。** 売上は顧客への提供コストを無視するため、LTV は売上ではなく限界利益で作る。
3. **少なくとも最初の12か月の月別解約曲線を作る、または推定する。** 単一の一定率にしない。実際のコホートデータがあれば直接使う。なければ、最終的な安定率を初日から適用するより、1〜3か月目は高く、6〜12か月目へ向け安定率まで下がる合理的な推定の方がはるかに実態に誠実である。
4. **付属の計算ツール（`scripts/unit_economics.py`）を実行する。** 月別の顧客残存率・限界利益、36か月での累積割引後 LTV、LTV:CAC、CAC 回収期間を得る。
5. **LTV:CAC を標準的な基準と照合する。** 3以上は一般に健全、1.5〜3は境界域（成長で売上が増えても顧客当たり価値を壊している可能性）、1.5未満は売上成長にかかわらず獲得が価値を壊している可能性が高い。
6. **比率と並べて回収期間を見る。** 比率が健全でも回収に18か月以上かかれば、実際の資金問題が生じる。CAC を支出してから回収するまでの差を事業が賄う必要があり、比率だけでは見えない別の問題である。
7. **入力が大きく違う場合はチャネル・コホート別に計算する。** 混合した LTV:CAC では、大幅赤字のチャネルが高収益チャネルに補助され、隠れる。`market-mapping` と同じ分解の規律を使う。
8. **一度だけでなく定期的に再計算する。** チャネルの飽和や競争変化で、解約曲線も CAC も動く。1年前の評価は現在の評価ではない。

## 入力
- 総費用を含む CAC（あればチャネル・コホート別）
- 顧客当たり月間売上と粗利益率
- 少なくとも最初の12か月の月別解約率。理想的には実際のコホートデータ
- 割引率（なければ年10〜15%の標準的な既定値を使う）
- `scripts/unit_economics.py` 冒頭で説明されている形式の JSON 設定ファイル

## 出力形式
月別の残存率・限界利益表。割引後 LTV、LTV:CAC、CAC 回収期間。標準的な基準に照らした平易な健全性評価（健全／境界域／価値毀損）。比率が良好でも回収期間により資金調達リスクが生じる場合の警告。

## 例
サブスクリプション事業が、最終的な安定率である月3%の解約を一律に仮定し、健全な LTV:CAC 4.2を求める。実際の初年度曲線（初月8%、6か月目までに3%へ低下）で作り直すと、比率は2.3となり、明確に境界域となる。回収期間10か月は単独では問題なくても、一定解約率モデルが示すほど速く成長予算を増やすと、資金に負荷がかかる。

## よくある落とし穴
- 「ARPU ÷ 解約率」の一定率の短縮式を使い、最終的な安定率を初月から適用することを暗黙に仮定して、LTV を大きく過大評価する。
- 限界利益でなく売上で LTV を計算し、顧客への提供コストを無視する。
- 回収期間を見ず比率だけを読み、健全に見えても実在する資金制約を見逃す。
- 全チャネルを混合した比率1つを計算し、健全なチャネルに補助される価値毀損チャネルを隠す。
